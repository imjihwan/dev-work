H3 영상 만들기

사진 넣고 → 무엇을 하는지 적고 → 모델 고르고 → 만들기. 영어로 쓰면 더 잘 알아듣습니다(한글도 됨).

1. 사진

여기로 끌어다 놓거나 클릭해서 고르기 · Ctrl+V 붙여넣기도 됨

2. 내용

생김새는 사진에서 가져오므로 성별·외모를 적지 않아도 됩니다. 사진에 없는 게 생기면 "유지할 것" 칸에 "no headband"처럼 적으세요.

3. 모델

저장한 조합
모델
속도·품질
LoRA — 동작·스타일을 더하는 추가 파일
고급 설정

4. 설정

최종 프롬프트 보기·직접 고치기
위 칸을 고치면 자동으로 다시 만들어집니다.

작업 이력

만들 때의 사진·설정·프롬프트와 결과 영상을 함께 남깁니다. 불러오기로 그때 구성을 화면에 다시 채웁니다. 기록을 지워도 영상 파일은 결과 폴더에 남습니다.
