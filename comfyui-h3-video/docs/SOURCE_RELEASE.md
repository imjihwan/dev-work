# 소스 배포 범위

소스 배포는 허용 목록을 기준으로 준비한다. `.gitignore`에 의존한 `git add .`로 설치 폴더 전체를 올리지 않는다.

## 포함

- `simple_ui/`의 Python·HTML·실행 파일, 비어 있는 `template_api.json`, 공개 초기 설정 `*.seed.json`.
- 설치·모델 다운로드·CPU 도우미 설치 코드와 테스트, 재사용 가능한 수동 유지보수 도구.
- README·변경 기록·설계/사용/검증 문서와 `versions.json`, `models.json`의 공개 설치 명세.
- 프로젝트 상대 경로로 동작하는 시작·종료·모델 확인 스크립트.

## 제외

- 사진·영상·음성·생성 중간 파일, 개인 프롬프트·작업 이력·저장 설정·프로젝트·갤러리 상태.
- 모델·LoRA·텍스트 모델 가중치, 설치된 ComfyUI와 커스텀 노드 복사본, 가상환경, CPU 도우미 바이너리.
- 로그·백업·다운로드·검증 결과물·PC별 방화벽 주소·현장용 스테이징 자료.

배포 준비는 아래 명령으로 소스만 별도 폴더에 복사한다. 입력·출력 폴더와 실행 중인 작업은 읽지 않는다.

```powershell
python scripts\prepare_source_release.py
```

기본 배포 경로는 `logs/source-release/comfyui-h3-video/`다. 허용한 파일만 복사하고, 빈 템플릿 프롬프트·사진 목록과 파일 확장자를 확인한다. 파일 목록과 SHA256 명세는 그 상위 폴더에 작성하므로 실제 배포 내용에는 들어가지 않는다. 이미 존재하는 배포 경로에는 덮어쓰지 않으며 새 `--destination`을 지정해 다시 준비한다.

GitHub 반영 전 최신 원격 커밋을 확인하고 `comfyui-h3-video/` 범위만 비교한다. 원격의 다른 프로젝트·파일은 유지한다. 인증·쓰기 권한이 없으면 로컬 준비와 원격 반영을 구분해 보고하며, 업로드되지 않은 상태를 완료로 표시하지 않는다.
