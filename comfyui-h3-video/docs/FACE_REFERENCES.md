# 여러 사진으로 얼굴 일관성 보강하기

## 확인한 동작

H3 Ref2VA는 이미지 참조를 최대 9장 받는다. 공식 프롬프트 가이드는 같은 대상을 여러 자료에서 참조할 때 하나의 `<Subject N>`으로 묶고 각 자료의 역할을 명시하도록 안내한다. 사진 9장을 별도 인물이나 순서대로 재현할 포즈로 설명하지 않는 것이 이 화면의 목적이다.

이 화면의 서버는 사진 배열을 같은 순서의 Director slot/order로 전달한다. Director는 사진 참조를 순서대로 수집하고 H3 노드는 각 참조를 텍스트 인코더와 연결된 video VAE 경로에 전달한다. 합성 입력 9장으로 제출 순서와 첫 사진 고정 연결을 검사했다. 실제 개인 사진이나 생성 결과를 검사한 것은 아니다.

참조 처리 코드는 얼굴을 자동으로 검출·분리하지 않고 이미지 전체를 축소해 사용한다. 따라서 ‘얼굴 보조’는 프롬프트로 지정한 역할이다. 배경과 옷이 많은 전신 사진보다는 얼굴이 충분히 크게 나온 보조 사진이 얼굴 정보를 더 잘 전달할 수 있다는 판단이며, 이 화면에서 품질 향상 수치를 측정한 것은 아니다.

소스 템플릿의 기본 `ref_image_size`는 `match`다. 각 사진을 비율을 유지하며 생성 영상의 픽셀 면적에 맞춰 축소한다. `max`는 더 높은 참조 해상도를 허용하지만 참조 정보가 매 샘플링 단계에서 사용되므로 시간·메모리 부담이 커질 수 있다. 이번 변경에서는 참조 해상도·모델·LoRA·스텝을 바꾸지 않았다.

첫 장면 고정은 첫 프레임 위치에 넣는 가이드다. 영상 전체에서 얼굴의 모든 픽셀이나 표정이 고정되는 기능은 아니므로, 이후 표정·가림·움직임 중에도 정체성이 유지되도록 별도의 참조 설명이 필요하다.

## 사진 구성

- 사진 1: 얼굴, 머리, 체형, 옷·악세사리, 장면의 기준 사진.
- 사진 2~9: 같은 인물의 선명한 얼굴 보조 사진. 정면과 완만한 좌우 측면 등 실제로 다른 정보를 제공하는 사진을 고른다.
- 얼굴 형태가 달라 보일 정도의 보정, 큰 나이 차이, 심한 가림·흔들림·극단적인 광각 사진은 참조 간 충돌 가능성을 늘릴 수 있다. 서로 일관된 사진으로 비교하는 것을 권한다.
- 얼굴 보조 사진의 표정이나 고개 방향은 영상에서 따라 할 동작이 아니다. 기본 얼굴 방향과 상·하체 동작은 사진 1 및 기존 장면 지시가 담당한다.

9장을 모두 쓸 수 있지만 장수가 늘수록 품질이 단조롭게 좋아진다는 보장은 없다. 같은 조건에서 적은 장수와 9장을 비교하되 사진 1·시드·모델·LoRA·장면을 유지하면 차이를 판단하기 쉽다. 모델·LoRA 변경이나 과격한 얼굴 동작을 함께 바꾸면 사진 효과를 구분하기 어렵다.

여러 사진을 하나의 영상에 함께 참조하려면 **기본 대기열 추가**를 사용한다. 사진 개별 추가는 사진당 별도 작업이며, 사진 순차 추가는 기준 사진을 회전한다. 기준 얼굴·의상·구도를 유지하려는 비교에는 일반 추가가 적합하다.

## 이번 코드 보완

1. 여러 파일을 병렬로 읽은 완료 순서가 사진 번호를 결정하던 부분을 수정했다. 이제 브라우저가 전달한 선택 순서대로 하나씩 읽으며 남은 참조 슬롯까지만 읽는다. 첫 사진 읽기에 실패하면 다음 사진을 조용히 기준으로 승격하지 않는다.
2. 인물 설명에 `<Picture 1>`이 이미 있어도 사진 2~9의 얼굴 역할이 빠지지 않도록 자동 조립을 수정했다. 실제 등록 장수의 사진 번호를 모두 쓰고 하나의 인물로 연결한다.
3. 보조 사진이 새로운 표정·고개 회전·카메라 이동·장면 전환을 요청하지 않도록 명시했다. 표정·말하기·눈 깜박임 중 얼굴 비율과 자연스러운 비대칭을 유지하도록 보강한다. 기존 카메라·상체·하체 지시는 보존한다.
4. 직접 편집하거나 이력에서 복원한 최종 프롬프트는 자동으로 덮어쓰지 않는다. `현재 사진 참조 문구만 반영`을 누르면 얼굴 참조 문단만 추가·갱신한다. 다른 문장·장면 시각·직접 편집 상태는 유지한다. 이 기능이 넣은 문구는 반복해서 눌러도 중복되지 않으며 사진 수가 줄면 해당 문구의 사진 번호도 갱신한다.

수정은 앞으로 화면에서 조립하거나 사용자가 명시적으로 갱신한 프롬프트에 적용된다. 이미 대기 중이거나 실행 중인 작업을 자동으로 수정하지 않는다. 사진을 보고 인물을 검증하거나 결과 영상을 분석하는 기능을 추가하지 않았다.
