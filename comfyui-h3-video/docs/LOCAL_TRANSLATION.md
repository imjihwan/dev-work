# 로컬 한국어 번역 미리보기

일반 화면의 **2. 내용 → 영문 → 한국어 미리보기 · 로컬 CPU**를 켜고 번역할 입력 칸을 누른다. 입력을 잠깐 멈추면 원문 아래의 접이식 영역에 번역을 표시한다. 대상·유지 조건·요약·장면별 동작·장소/카메라·소리·음악·최종 프롬프트와 도우미 텍스트에 사용할 수 있다.

미리보기는 읽기 전용이다. 원문·최종 프롬프트·생성 설정·사진·대기열을 번역문으로 덮어쓰지 않는다. 한국어로 작성한 내용은 영문으로 바꾸지 않는다. 번역은 참고용이며 실제 생성에는 원래 입력을 사용한다.

기본 **정밀**은 기존 로컬 AI로 문맥·부정·방향·촬영 용어를 고려해 번역한다. 긴 글은 시간이 걸린다. **빠르게**는 영어→한국어 전용 모델로 빠르게 확인하는 선택지다. 두 방식 모두 오역할 수 있으므로 뜻이 이상하면 정밀로 다시 확인한다. 영상 생성 프롬프트나 워크플로 모델을 교체하는 기능이 아니다.

## 긴 문장과 입력 변경

- 현재 칸만 정밀은 최대 480자, 빠르게는 최대 900자 단위로 나눈다. 문장·문단 경계를 우선하고, 긴 단일 문장은 단어 경계로 나눈다. 각 구간 전체를 문맥으로 번역하며 원문을 잘라 버리거나 요약하지 않는다.
- 결과가 나오는 부분부터 표시하고 진행 개수를 보여 준다. 번역 영역은 최대 260px 또는 화면 높이의 40%까지만 펼치며 내부에서 스크롤한다.
- 바뀌지 않은 구간은 메모리 캐시를 재사용한다. 문단 사이에서 구간을 끊으므로 한 문단을 고쳐도 다른 문단의 번역을 다시 요청하지 않는다.
- 드래그로 일부를 선택하면 선택 부분만 번역한다. 64,000자를 넘는 전체 입력은 임의로 자르지 않고 선택 번역을 안내한다.
- 입력을 고치거나 다른 칸으로 이동하면 늦게 도착한 이전 결과를 반영하지 않는다. 다시 번역 버튼으로 해당 구간의 캐시를 비울 수 있다.
- `<Picture 1>`, `<Subject 1>`, `{{face_side}}`, 시간 코드 등은 보호한다. 표기 보존에 실패한 구간은 원문으로 표시하고 상태에 안내하며 나머지 번역을 계속한다.

## 실행 환경과 데이터

정밀은 [Google TranslateGemma 4B](https://huggingface.co/google/translategemma-4b-it)의 [Q4_K_M 변환본](https://huggingface.co/Menterium/translategemma-4b-it-GGUF)(약 2.49GB)을 CPU llama.cpp 프로세스로 실행한다. 기존 프롬프트 도우미의 실행 파일만 재사용하며 도우미 모델은 바꾸지 않는다. 빠르게는 [QuickMT 영어→한국어 전용 모델](https://huggingface.co/quickmt/quickmt-en-ko)을 CTranslate2 INT8로 실행한다. 기존 Argos와 Qwen 2B는 번역에 사용하지 않는다. 고정 버전·다운로드 주소·크기·SHA256 및 라이선스는 `models.json`의 `local_translation`에 기록한다. TranslateGemma는 Gemma 이용 조건을 따른다. 설치는 다음과 같다.

```powershell
.\ComfyUI\.venv\Scripts\python.exe scripts/install_local_translator.py
```

ComfyUI 폴더와 같은 위치의 `local-translator` 안에 별도 Python 환경과 모델을 둔다. ComfyUI 패키지·영상 모델·워크플로 노드는 변경하지 않는다. 영상 생성 모델과 프로세스도 재시작하지 않는다.

추론은 GPU를 사용하지 않고 CPU 두 스레드, 번역 프로세스 하나, 낮은 실행 우선순위로 제한한다. 방식을 바꾸면 번역기가 직접 시작한 기존 프로세스만 중지한다. 프롬프트 작성 도우미를 시작하면 번역 프로세스를 중지해 도우미를 우선하며, 동시 번역 요청은 대기한다. 사용 후 45초가 지나면 모델 프로세스를 종료한다. 정밀은 RAM 여유 4GB 미만에서 시작을 기다리고 2.5GB 미만에서 종료한다. 빠르게는 각각 3GB/2GB다. 한 구간의 제한 시간은 정밀 90초, 빠르게 30초다. 입력 변경 시 이전 응답을 무시하지만 이미 시작한 추론은 해당 구간까지 실행될 수 있다. CPU·RAM은 영상 작업과 공유하므로 영향이 완전히 0인 것은 아니다.

초기 설치에만 공개 모델·패키지 다운로드가 필요하다. 번역은 서버 PC에서만 수행하며 외부 번역 서비스로 텍스트를 보내지 않는다. 번역 기능은 번역용 입력/결과를 로그·파일·브라우저 저장소에 별도로 저장하지 않는다. 기존 화면의 원문 저장 동작은 유지한다. 번역 기능이 브라우저에 저장하는 것은 켜기/끄기와 번역 방식뿐이다. 서버와 브라우저의 결과 캐시는 각 128개로 제한하며, 번역 방식별 결과를 섞지 않는다.

API는 `/api/translate`에 한 구간의 `text`와 선택적인 `engine`(`quality` 기본 / `fast`)을 받고 번역문을 반환한다. 사진·작업 이력·결과 파일을 읽는 API를 사용하지 않는다. 테스트는 합성 텍스트와 가짜 프로세스·DOM을 사용한다. 실제 모델 동작 확인도 별도의 합성 예문으로 수행한다.
