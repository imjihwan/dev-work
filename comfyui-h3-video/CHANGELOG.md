# 변경 기록

## 2026-11-16

- 사진 순차 추가에서 CPU로 가장 큰 얼굴 주변을 크롭해 보조 참조로 사용한다. 각 작업의 사진 1·첫 장면 고정·자동 화면비는 원본을 사용하고, 검출 실패 시 원본으로 대체한다. 크롭은 사진당 한 번만 준비하며 실제 제출한 참조 조합을 이력에 남긴다.

- 최대 9장의 얼굴 참조 역할이 기존 인물 설명의 사진 태그 때문에 누락되지 않도록 보완했다. 한 사람으로 연결하고 보조 사진의 표정·고개 각도를 동작 지시와 분리한다. 파일 읽기 완료 순서에 따라 기준 사진이 바뀌던 문제를 고쳤으며, 직접 편집한 최종 프롬프트의 참조 문구만 갱신하는 버튼을 추가했다.

- 이력 페이지에 불러오지 않은 항목까지 수정하는 전체 대기항목 일괄수정을 기본 동선으로 추가했다. 저장 시 대상 대기열을 다시 확인하며 실행 중인 작업과 대기 순서를 보존한다.
- 갤러리에서 대상 영상과 설정 출처 영상을 선택해 프롬프트·모델 설정을 복사하고 우선 재생성할 수 있다. 중복 제출 방지, 완료 표시·상단 이동, 현재 작업 진행률을 추가했다.
- iPad 재생 안정성을 위해 이력 썸네일의 영상 선로딩을 화면에 보이는 최대 6개로 제한하고 숨김·재생창 전환·다시 그리기 시 버퍼를 해제한다. 단일 영상 스와이프에서 플레이어를 재사용하고 불필요한 비동기 대기를 제거했다. 실제 iPad 메모리 사용량을 측정한 결과는 아니다.
- 개인 데이터·모델·미디어·설치본·로그·백업 제외 규칙을 보강하고 배포용 파일을 명시했다. 설치 스크립트는 허용한 UI 코드·초기 설정만 복사한다.

## 이번 업데이트에 함께 정리한 기능

- 일반 생성과 분리된 네 편 이어 만들기 및 CPU 프롬프트 작성·부분 수정·동작/시간 검토.
- 설정 저장·불러오기, 대기항목 개별/선택 일괄수정, 사진 회전 순차 추가, 사진별 개별 추가의 100장 제한 해제.
- 작업 이력 무한 스크롤, 대기 번호, 원본 사진 표시, 이력 삭제와 ComfyUI 대기열 연동, 현재 작업 재시작.
- 최대 3개 선택 영상 재생, 반응형 재생창, 전역 LoRA 표시, 영상 밖 설정 표시, 선택하지 않은 영상의 즉시 단독 재생.
- 모바일 갤러리, 첫 원본 사진 썸네일 캐시, 자동 갱신, 즐겨찾기·휴지통·복원, 이전/다음 스와이프.
- 공통 참조 조건과 시작 동작 문구의 저장 화면 복원·마이그레이션, 장면 변경과 최종 프롬프트 동기화.

개별 작업·프롬프트·사진·결과·사용 모델 목록은 변경 기록에 포함하지 않는다.
