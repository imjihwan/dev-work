# 변경 기록

## 편집 재량 확대와 일괄 요청 처리

- 문구 보존·공통 항목 기본 보호 지침과 명령어 기반 자동 실행 판별을 제거했다.
- 일괄 요청은 개별 항목 계획 대신 하나의 일괄 API를 사용하며, 서로 다른 프롬프트의 공통 구간도 한 번에 수정할 수 있다.
- 기존 확인/자동 선택, 실행 중 보호·정확한 대상 검사·중복 실행 방지를 유지한다.

## 대화형 도우미의 공통 조건 오류 반복 수정

- 공통 항목명 키워드 검사를 없애고 최근 대화·미적용 수정안과 후속 승인을 함께 해석한다.
- 도우미가 목적에 맞춰 조회·제안·수정을 이어가도록 지시문을 정리하고 불필요한 재확인을 줄였다.
- 기존 오류는 표시 기록을 지우지 않고 다음 모델 요청의 맥락에서만 제외한다. 실행 검증과 확인/자동 설정은 유지한다.

## Grok 실시간 처리 단계

- CLI 이벤트를 실행 중 읽어 연결·대기·추론·답변 작성 단계를 표시한다. 진행 신호 수와 마지막 수신 시간을 제공한다.
- 새로고침·다른 기기에서도 동일한 진행 상태를 표시하며 내부 사고 원문이나 미완성 변경안을 노출·실행하지 않는다.

## 새로고침 후 진행 중 요청 이어보기

- 기존 요청을 다른 기기로 잘못 단정하던 문구 대신 처리 단계·차수·경과 시간을 표시한다.
- 복원한 현재 도우미 요청의 취소를 지원하고 완료 뒤 대기 표시와 입력 잠금을 해제한다. 새 요청이나 이전 실행을 재전송하지 않는다.

## Grok 고정 3분 제한 수정

- 모드별 호출 예산과 요청 전체 예산을 적용해 긴 응답을 일률적으로 180초에 종료하지 않는다.
- 취소와 자동 재전송 방지를 유지하며 현재 제한과 숫자 기반 진단을 제공한다. 실제 대화·작업 원문을 진단 로그에 남기지 않는다.

## 새 답변 빨간 점

- 제작 도우미의 미확인 답변을 표시하고 열어 확인하면 지운다. 공유 대화와 브라우저별 읽음 상태를 지원한다.

## 제작 도우미 공통 대화

- 대화를 PC 서버에 보관해 휴대폰·아이패드·다른 접속 주소에서도 이어 본다. 작성 중인 입력은 기기별로 유지한다.
- 기존 브라우저 기록을 빈 서버에 한 번만 이관하고 갱신 충돌·원치 않는 덮어쓰기를 막는다.
- 다른 기기의 제안은 읽기 전용으로 복원하고, 서버 재시작이나 새 대화 뒤에 이전 동작을 재실행하지 않는다.

## Grok 응답 개선과 품질 선택

- Grok 4.7 정밀 모드를 기본으로 유지하며 최대/균형/빠르게 선택과 처리 단계·경과 시간을 추가한다.
- 최초 대기열 전달을 20개로 제한하고 추가 페이지·지정 항목 조회, 전체 로컬 검증을 유지한다.
- 동일 요청 안의 중복 조회·중복 결과와 불필요한 JSON 구분 공백을 줄인다. 프롬프트 문자열은 보존한다.
- 사용자 작업을 열람하지 않는 인수인계 문서를 추가한다.

## 제작 도우미 대화 유지

- 최근 대화·작성 중인 입력·변경안 표시와 실행 결과를 브라우저에 저장하고 새로고침 후 복원한다.
- 복원한 변경안은 읽기 전용으로 표시하고 자동 재실행하지 않는다. 새 대화는 로컬 대화 기록도 지운다.
- 저장 실패·깨진 데이터·기록 용량 제한을 처리한다.

## 2B 로컬 도우미 제거

- 일반·이어 만들기 화면에서 2B 선택을 제거하고 이전 2B 선택을 DutchIT로 전환한다.
- 로컬 2B 가중치를 삭제하고 기본 도우미 설치는 DutchIT만 준비한다. Grok·영상 생성 모델과 설정은 유지한다.

## 영상 제작 도우미 대화형 UI

- PC는 작업 영역 옆에 붙는 채팅 패널, 모바일·태블릿은 넓은 대화 화면으로 구성했다. 열림/접힘을 브라우저별로 유지하고 넓게·분할 보기·접기를 지원한다.
- 말풍선 대화 안에 변경 전후와 실행 버튼을 넣고, 이전 제안과 실행 상태를 대화에 남긴다. 응답 대기 표시·예시 요청·길이에 맞춘 입력칸·이전 대화 스크롤 유지와 최신 대화 이동을 제공한다.
- Enter/Shift+Enter·터치 키보드·한국어 IME를 구분하고 채팅 입력이 원래 편집/프로젝트를 변경 상태로 표시하지 않게 했다. 실제 페이지 대신 합성 화면으로 PC·태블릿·모바일을 검증했다. 생성·대기열·서버 기능은 유지한다.

## Grok 웹 영상 제작 도우미

- 일반·갤러리·이어 만들기 화면에 제작 도우미 패널을 추가했다. 현재 입력·자동/수동 최종 문구·상태 메시지와 앱 API를 참고해 설명 또는 변경안을 만든다.
- 다른 대기 항목은 필요할 때 번호/ID로 실제 실행 문구를 조회한다. 정확한 부분 교체와 문구 해시·전체 그래프 대조로 오래된 문구의 덮어쓰기를 막는다.
- 웹 조작·대기열·모델/LoRA·설정 묶음·갤러리·이어 만들기 API를 연결했다. 기본 확인 모드와 명확한 요청의 자동 실행 선택, 단계별 실행 기록·입력/사진 변경 감지·결과 불명 시 재실행 금지를 제공한다.
- CLI 파일/셸/검색 도구는 계속 비활성화하고, 사진 바이트는 모델에 전달하지 않는다. 현재 사진을 사용하는 요청은 브라우저에서 기존 로컬 앱 API로만 전달한다. 설치 복사 목록에 필요한 도우미·번역 모듈도 포함했다.
- 개인 작업이나 실제 앱 대기열을 사용하지 않고 합성 화면·대기 항목·모의 API 및 실제 CLI로 검증했다.

## 2026-11-18 (전체 대기항목 프롬프트 반영 검증)

- 이력·저장 설정에서 불러온 수동 최종 프롬프트가 있는 경우, 저장 직전에 2번 칸과 장면 입력을 다시 대조한다. 입력 이벤트가 누락돼도 바뀐 내용을 재조립하며, 그 뒤 사용자가 명시적으로 편집한 최종 문구는 보존한다.

- 수정 API의 성공 응답 뒤 실제 ComfyUI 대기·실행 항목 또는 완료 기록에서 해당 ID의 실행 그래프를 대조한다. 일치한 경우만 성공으로 기록하고 대조 확인 수를 응답한다. 항목별 복구 사본을 분리해 다음 항목의 수정이 앞선 실패 사본을 덮어쓰지 않게 했다.
- 실제 개인 대기열·문구·미디어를 사용하지 않고 입력 이벤트 누락, 부분 실패, 성공 응답과 실제 큐 데이터 불일치 및 전체 수정 경로를 합성 데이터로 재현했다.

## 2026-11-18 (브라우저별 기본 음소거)

- 상단·갤러리·이어 만들기에 ‘기본 음소거’ 설정을 추가했다. 선택은 브라우저 저장소의 독립 키에만 저장하며 같은 접속 주소의 화면·탭끼리 동기화한다. 서버 공용 설정·생성 요청·프로젝트에는 넣지 않는다. 처음 선택하지 않은 브라우저는 기존처럼 첫 영상 소리를 켠다.
- 새 재생창은 저장된 기본값을 적용하고 다중 재생에서는 한 영상만 소리를 낸다. 갤러리에서 넘길 때는 재생 중 직접 조절한 음소거·음량을 유지한다. 기본값 변경은 현재 영상을 다시 만들거나 재생 위치를 초기화하지 않는다. 이력 썸네일 미리보기는 계속 음소거한다.

## 2026-11-18 (대기열 보존 백엔드 재시작)

- ComfyUI 재시작 중 UI의 상태 조회를 보류하고 새 작업·삭제·편집 요청을 차단한다. 폼 자동 저장은 유지하고, 실행 시작 이벤트에서는 예전 진행률을 초기화한다.
- 명시적으로 실행하는 `scripts/restart_backend.py`는 대기열·이력을 비공개 로컬 사본으로 검증 후 백업하고, 대기 작업을 분리한 뒤 알려진 실행 항목만 중단한다. 실행 항목을 먼저 두고 ID·실행 그래프·클라이언트 정보를 보존해 재등록한다. 새 대기번호를 순차 배정해 이후 추가되는 작업의 순서도 유지한다.
- 자연 완료된 항목은 중복 생성하지 않고 UI 이력에 반영한다. 복원 후 항목 수·ID·순서·그래프·설정을 대조하며 실패하면 보호 상태와 복구 자료를 유지한다. 진행 중 계산은 이어서 재개되지 않으며 처음부터 시작한다. 개인 백업·시작 로그는 Git에 포함하지 않는다.
- 대기열·중단 API의 빈 성공 응답을 지원하고, 백엔드를 아직 종료하지 않은 실패는 같은 백업에서 이어간다. 재등록이 끝난 상태는 중복 제출 없이 검증만 다시 실행할 수 있다. 서버가 재정렬하는 내부 출력 대상은 집합으로, 실제 대기 순서는 순서대로 대조한다.

## 2026-11-17 (DutchIT CPU 메모리 보완)

- DutchIT의 키·값 캐시를 Q8_0으로 설정하고 CPU Flash Attention을 사용한다. 가중치 재배열의 모델 크기 추가 버퍼가 시작 중 메모리 보호 중지를 유발해 `--no-repack`을 적용했다. 가중치·8,192 문맥·두 스레드·GPU 레이어 0·8GiB 시작 및 2.5GiB 실행 제한은 유지한다.
- 기존 2B·번역기 옵션은 유지하고 DutchIT 전용 옵션을 회귀 검사한다. 실제 응답 검증에는 별도 합성 입력만 사용하며 작업 이력·사진·영상은 조회하지 않는다.
- 실제 합성 응답에서 길이를 벗어난 장면 시작 시각이 발견되어 DutchIT 새 초안의 시각을 영상 길이 안의 0.1초 단위로 JSON 문법에서 제한했다. 부분 수정의 원래 시각과 기존 2B 형식은 바꾸지 않는다.
- 합성 응답의 `camera smoothly pushes` 같은 중복 촬영 문구를 검사하도록 보완했다. 새 초안만 적용 전에 최대 한 번 다시 작성하고 검사하며, 기존 문장·부분 수정은 자동 재작성하지 않는다.
- 실제 8B CPU에서 합성 새 초안·검토(155.5초)와 음악만 부분 수정·검토(103.4초)를 확인했다. 성공 요청의 최대 작업 집합 5.07GiB·최소 여유 RAM 4.14GiB였고 종료 후 모델 프로세스가 해제됐다. 영상 생성 프로세스·대기열은 유지하고 개인 작업·사진·영상은 조회하지 않았다.

## 2026-11-17 (DutchIT CPU 프롬프트 도우미)

- 일반 화면·네 편 이어 만들기에 DutchIT H3 8B와 기존 2B 선택을 추가했다. DutchIT의 공개 지시문을 기존 편집기에 맞게 수정하고 기반 8B Q4_K_M을 CPU 두 스레드·GPU 레이어 0으로 실행한다. 사진은 전달하지 않는다.

- 얼굴 크롭을 **얼굴인식강화** 옵션(기본 꺼짐)으로 바꿨다. 켜면 일반 추가·순차 추가 모두 사진 2부터 얼굴 크롭을 쓰고, 첫·끝 장면 방식과 대기항목 수정에는 적용하지 않는다.
