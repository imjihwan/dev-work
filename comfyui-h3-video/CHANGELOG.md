# 변경 기록

## 2026-11-16 (도우미 품질·얼굴인식강화)

- 프롬프트 도우미가 요청에 없는 옷·소품·장소를 지어내던 문제: 지시문의 물건 예시 제거, 분량 목표 축소·자동 상세 보강 끔, 요청에 없는 외모·소품·장소 단어를 코드로 빼고 검토 결과에 표시. 문장 전체가 아니라 그 단어가 든 구·절만 잘라 동작 문장은 남긴다(검토 결과에 뺀 부분 표시).
- 도우미 새 초안의 장면 시각이 앞쪽 0~2초에 몰리던 것을, 동작 분량에 맞춰 영상 전체에 다시 나눈다.
- 처음 예시(서버에 화면 상태가 없을 때 쓰는 기본값)를 세발자전거 체크포인트 프롬프트(7초, 장면 0·1·2.6·3.4·4.4·6.2초)로 바꿨다.
- 창마다 브라우저에 따로 저장하던 화면 칸·설정·사진을 서버 한 곳에 두고 모든 창이 따라가게 했다. 다른 창이나 이력 불러오기·일괄수정이 남긴 값(길이·첫 장면 고정·시드)이 다른 창의 설정을 덮어쓰던 문제를 없앴다. 대기항목 수정·일괄수정 중 불러온 값은 공유하지 않고, 끝나면 들어가기 전 화면으로 돌아간다.
- 작업이력에서 항목 어디에든 마우스가 닿으면 LoRA·설정 팝업이 떠서 목록을 가리던 것을, `설정` 버튼에 올릴 때만 열리게 했다.
- 얼굴 크롭을 **얼굴인식강화** 옵션(기본 꺼짐)으로 바꿨다. 켜면 일반 추가·순차 추가 모두 사진 2부터 얼굴 크롭을 쓰고, 첫·끝 장면 방식과 대기항목 수정에는 적용하지 않는다.

## 2026-11-16 (리뷰 반영)

- 대기항목 일괄수정의 '내용'이 사진 수가 다른 항목에도 첫 항목 기준 얼굴 참조 문구를 넣던 문제: 항목마다 자기 사진 수에 맞는 문구로 저장한다. 사진별 개별 추가도 직접 고친 최종 프롬프트에서 여러 장용 문구를 뺀다.
- 이력 '불러오기'·'수정'을 연달아 누르면 두 항목 내용이 섞이던 문제: 마지막 요청만 반영하고 사진을 다 받은 뒤 한 번에 바꾼다.
- 여러 편 등록 중간에 실패하면 이미 대기열에 들어간 작업이 이력에 남지 않던 문제를 고쳤다.
- 네 편 이어 만들기: 상태 조회의 일시 오류(타임아웃·연결 끊김)를 실패로 확정하지 않고 다시 묻는다. 병합 중·실패한 영상이 갤러리에 보이지 않게 임시 이름으로 쓰고 검증 후 옮긴다. 중지 신호를 먼저 보낸다.
- 갤러리 원본 썸네일 생성을 잠금 밖에서 해 상태·이력 조회가 막히지 않게 했다.
- 얼굴 검출 모델이 없으면 사진 순차 추가가 실패하던 문제: 원본 사진으로 진행하고 이유를 표시한다.
- 대기 작업이 있을 때 10초마다 이력 전체를 다시 그리던 것: 진행률·대기 순번만 바뀌면 그 칸만 고친다. 서버는 이력 한 페이지에 대기열을 한 번만 조회한다.
- ComfyUI 위치 규칙을 스크립트 전체에 맞췄다(`-ComfyDir` → 프로젝트 안 `ComfyUI` → `%USERPROFILE%\ComfyUI`). 프롬프트 도우미는 ComfyUI 폴더 옆에 설치한다.
- TODO 에서 빠졌던 미구현 항목(SeedVR2 참조 사진 업스케일, 보류 아이디어)을 되살렸다.

## 2026-11-16

- 사진 순차 추가에서 CPU로 가장 큰 얼굴 주변을 크롭해 보조 참조로 사용한다. 각 작업의 사진 1·첫 장면 고정·자동 화면비는 원본을 사용하고, 검출 실패 시 원본으로 대체한다. 크롭은 사진당 한 번만 준비하며 실제 제출한 참조 조합을 이력에 남긴다.

- 최대 9장의 얼굴 참조 역할이 기존 인물 설명의 사진 태그 때문에 누락되지 않도록 보완했다. 한 사람으로 연결하고 보조 사진의 표정·고개 각도를 동작 지시와 분리한다. 파일 읽기 완료 순서에 따라 기준 사진이 바뀌던 문제를 고쳤으며, 직접 편집한 최종 프롬프트의 참조 문구만 갱신하는 버튼을 추가했다.

- 이력 페이지에 불러오지 않은 항목까지 수정하는 전체 대기항목 일괄수정을 기본 동선으로 추가했다. 저장 시 대상 대기열을 다시 확인하며 실행 중인 작업과 대기 순서를 보존한다.
- 갤러리에서 대상 영상과 설정 출처 영상을 선택해 프롬프트·모델 설정을 복사하고 우선 재생성할 수 있다. 중복 제출 방지, 완료 표시·상단 이동, 현재 작업 진행률을 추가했다.
- iPad 재생 안정성을 위해 이력 썸네일의 영상 선로딩을 화면에 보이는 최대 6개로 제한하고 숨김·재생창 전환·다시 그리기 시 버퍼를 해제한다. 단일 영상 스와이프에서 플레이어를 재사용하고 불필요한 비동기 대기를 제거했다. 실제 iPad 메모리 사용량을 측정한 결과는 아니다.
- 개인 데이터·모델·미디어·설치본·로그·백업 제외 규칙을 보강하고 배포용 파일을 명시했다. 설치 스크립트는 허용한 UI 코드·초기 설정만 복사한다.

## 이번 업데이트에 함께 정리한 기능

- 일반 생성과 분리된 네 편 이어 만들기 및 CPU 프롬프트 작성·부분 수정·동작/시간 검토.
- 설정 저장·불러오기, 대기항목 개별/선택 일괄수정, 사진 회전 순차 추가, 사진별 개별 추가의 100장 제한 해제.
- 작업 이력 무한 스크롤, 대기 번호, 원본 사진 표시, 이력 삭제와 ComfyUI 대기열 연동, 현재 작업 재시작.
- 최대 3개 선택 영상 재생, 반응형 재생창, 전역 LoRA 표시, 영상 밖 설정 표시, 선택하지 않은 영상의 즉시 단독 재생.
- 모바일 갤러리, 첫 원본 사진 썸네일 캐시, 자동 갱신, 즐겨찾기·휴지통·복원, 이전/다음 스와이프.
- 공통 참조 조건과 시작 동작 문구의 저장 화면 복원·마이그레이션, 장면 변경과 최종 프롬프트 동기화.

개별 작업·프롬프트·사진·결과·사용 모델 목록은 변경 기록에 포함하지 않는다.
